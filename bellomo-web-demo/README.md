# EverProp Bellomo

Base visual pública para demo comercial EverProp aplicada a Bellomo.

## Stack

- Next.js
- TypeScript
- Tailwind
- App Router

## Objetivo

Web pública inmobiliaria mobile-first para:
- Presentar loteos y propiedades.
- Capturar leads por WhatsApp/formulario.
- Preparar conexión futura con API Laravel + MySQL.
- Mantener datos aislados por `company_id` cuando pase a backend real.

## Nota de marca

El wordmark incluido es una referencia visual para demo. Para producción se debe reemplazar por assets oficiales provistos por Bellomo.
